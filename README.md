# Agenda Caleta

## Descripción
Agenda Caleta es un proyecto web destinado a mostrar información sobre actividades, eventos y propuestas de interés en Caleta Olivia.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Git y GitHub

## Integrantes
- David Aibar
- Aquiles Prado

## Archivos del proyecto
- `índex.html`: estructura principal de la página.
- `style.css`: estilos y diseño visual.
- `script.js`: funcionalidades e interacciones.

## Ejecución
Abrir el archivo `índex.html` en un navegador web.

## Trabajo grupal
El proyecto se desarrolla colaborativamente utilizando Git para el control de versiones y GitHub para alojar el repositorio remoto.
